# Étude des commandes – CAFPI

Tableau de bord Smartshop. La page ne contient aucune donnée : elles sont stockées dans Firebase (collections `cafpi_base`, `cafpi_datasets`, `cafpi_history`), accessibles aux comptes de la liste `authorizedUsers`.

Ne déposez jamais `donnees-initiales.json` ni de fichiers Excel du client dans ce dépôt.
